# Problema de Transporte - Solução Inicial

Programa em Python para resolver o problema clássico de transporte utilizando os métodos:
1. Canto Noroeste
2. Custo Mínimo
3. Vogel (VAM)

## Requisitos

- Python 3.10+

## Como Executar

1. (Opcional) Ative o ambiente virtual, se houver:
   ```bash
   source .venv/bin/activate  # Linux/macOS
   # ou
   .venv\Scripts\activate     # Windows
   ```

2. Execute o arquivo principal:
   ```bash
   python main.py
   ```

3. Siga as instruções do terminal informando as dimensões, vetores de oferta/demanda, custos e o método desejado.
